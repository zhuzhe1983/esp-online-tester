Licences of the classic PSRAM IDF fixture
========================================

Source/recipe: docs/fixtures/classic-psram-idf (application: MIT, repository LICENSE).
SDK: ESP-IDF v4.4.7, 38eeba213aa695aabfd6d89aa9f5078dbe5a94c3.
Compiler: GCC 8.4.0, crosstool-NG esp-2021r2-patch5.

libgcc, libhal, libheap, liblog, libmain, libmbedcrypto, libnewlib, libpthread,
libsoc, libspi_flash, libvfs, libxt_hal and libxtensa.

libgcc, libhal, liblog, libmain, libsoc and libspi_flash.
No Wi-Fi, Bluetooth, lwIP, TLS protocol or proprietary PHY radio archive
contributes code to these images. Linked ESP-IDF initialization glue is not a
radio implementation.

Shared licence texts are retained in classic-hello-NOTICE.txt in this directory
(Apache-2.0, MIT, newlib notices, GPLv3 and runtime exception). The Xtensa HAL
MIT copyright/permission text is also retained with this fixture's SDK licences.
