ESP ONLINE TESTER · AGENT GUIDE

用智能体开发和测试 ESP 产品

智能体与人使用同一套 ESP32 产品运行环境：选择设备和配件，在浏览器的 WebAssembly worker 中执行固件，查看串口、屏幕和已实现的外设输出，再把场景分享或嵌入网页。

选择适合任务的 skill

01 / 操作与测试

esp-online-tester

适合已经在目录中的设备。让 coding agent 选择设备和固件、配置配件、触发按键或传感器输入，检查实际固件输出，保存录制并分享场景。

平台提供 window.espTester 和 iframe RPC；无须另起远程模拟器。

02 / 产品适配与入库

esp-product-onboarding

适合尚未适配或需要更新的产品、模块和固件。在仓库中核对厂家、SKU 和版本，采集有来源的规格与 CAD，制作和校验 3D 模型。

维护产品知识、固件目录和验收证据，再通过 PR 贡献。

  • 获取完整 skill 目录 ↗
  • 模型与贴图校验 · 固件来源与验证
阅读 esp-product-onboarding skill，为这个准确 SKU 和硬件版本补充官方资料、模型和固件，分别报告外观、运行验证及尚未支持的部分。

开始使用

  1. 让支持读取网页的智能体打开对应的 SKILL.md，并按需读取其 references。需要本地安装时，获取完整 skill 目录（包括 references），按智能体工具的安装方式使用；文件链接本身不会自动安装。
  2. 操作现有设备时打开实验台；导入产品时获取本仓库，并先读仓库的 AGENTS.md 和 skill。明确设备 SKU、版本和待验证的固件。
  3. 检查能力与支持范围。加载固件、发送输入后，观察新的串口、framebuffer 或外设输出，再记录结果和限制。

各产品的模拟支持程度不同。模型可以显示、输入已排队或固件在目录中，都不能证明完整兼容。网络访问可能需要自行部署的 helper；具体边界以 skill、能力查询与实际运行结果为准。
