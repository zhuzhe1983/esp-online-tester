# K138-V11 model and reference images

These unmodified product photographs and the dimension drawing were retrieved from M5Stack's official documentation. Source URLs, retrieval timestamps and SHA-256 values are recorded in `../../knowledge/m5stack-k138-v11.json` and `docs/platform/evidence/m5stack-k138-v11/source-audit.json` at the repository root.

Copyright remains with M5Stack. These reference assets are not relicensed under the repository's software license. They are not evidence of firmware execution or a complete v1.1 CAD assembly.

The shared frame/carrier/motor geometry comes from the official-document-linked StampFly Ecosystem project, under its retained `LICENSE-StampFly-Ecosystem.txt`. The exact Stamp-S3A cover comes from M5Stack M5_Hardware; its license is retained in `source-m5stack-license.txt`. Source receipts distinguish the repositories, revisions and hashes. Raw older battery and propeller approximations remain reproducible references and are not displayed as verified v1.1 parts.

`model-plan.json` records the selected source triangles, rigid transforms, photographic masks and estimated missing external pieces. Rebuild with `tools/rebuild-product-model.py`; see `docs/platform/stampfly-v11-onboarding.md` at the repository root for validation boundaries.
