# ESP32-S31 firmware placeholders

Pinned hello_world / bootloader / partition-table binaries for Machine acceptance
will live here once ESP-IDF **v6.1** with `--preview set-target esp32s31` is
available on the build host.

This Mac worktree currently has IDF 5.3/5.4 only, so no binaries are fetched yet.
See `tools/fetch-s31-firmware.sh` and `docs/evidence/s31-upstream/README.md`.

Do not drop Metalio INK4 product images here as upstream goldens.
