# C5 peripheral shutdown owner integration

The unchanged LCD273 factory image now executes the complete `esp_perip_clk_init` shutdown sequence, including real owner writes, the two LP_IO latch checks, PAU held-reset, six APM automatic-clock selections and LP clock-to-pad closure. It later prints the console GPIO12/11 configuration message, then stops before `app_main` at `42001118`, reading the still unsupported cache-error word `600c83d0`.

The focused integrated C5 suite passes **407 tests**, including all six pinned-input cases. Both workspace/all-target and release-WASM/jit-tests Clippy steps pass with warnings denied. These runs explicitly use one build job and `CARGO_PROFILE_RELEASE_LTO=false`; they do not replace the final default-LTO CI or product acceptance.

The new ten integration cases exercise real Bus/guest paths: all RMT gate planes and preserved legacy behavior; plain/priced ModelLimit without fabricated guest exception CSRs; transactional selection with prior RMT activity; distinct general timer/MWDT/APB owners; watchdog counting with APB off and earlier-reset barriers; CPU/HP/LP/raw retention; both LP_IO latches and stopped RNG samples; and six observed Machine APM clock stores without DMA/world grants. Deliberately seeded RMT state is a component negative control, not original firmware output.

Original native receipt: **26,620,301 steps/insn_count / 26,620,288 nominal cycles / 2,263 UART bytes**; bulk PCR/LP writes **31/3**, PAU reset held, CLK_OUT/LP_UART/LP_GPIO zero, APM modes all automatic0 with six clock writes, original teardown counts still4/15/1. CPU240MHz, AHB/APB40MHz and LP_FAST17.5MHz/LP_SLOW136kHz remain explicit functional observations. The PSRAM selftest success log is retained; LCD pixels and SD commands remain zero.

`integration-checks.json` records source/module revisions, exact commands, input/log hashes, checks and limits. The raw probe and earlier unsupported-RMT negative result remain in the ignored input cache. No ROM/factory bytes, host jump, forced ACK or success frame were changed. Independent wiring review retained two P2 findings: HP reset incorrectly reconstructed LPPERI while LP_GPIO retained, and LPPERI accesses crossed pending/overdue watchdog resets. Both are repaired and covered by new real-MMIO negative cases; the final original native log is byte-identical to the initial integration run. Final read-only review matched source and log hashes and closed both findings, with no remaining P1/P2 in this wiring scope; its artifact hash is in the receipt.
