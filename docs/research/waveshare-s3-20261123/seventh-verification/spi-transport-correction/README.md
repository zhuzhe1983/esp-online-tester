# ST7789 serial MOSI correction

The 1.9-inch ST7789V2 and 1.3-inch ST7789VW board adapters previously rejected a whole write whenever SPI also requested read clocks or used full duplex. Readback is still an unimplemented floating-FF subset, but that does not disconnect the physical MOSI wire. The adapters now consume correctly wired single-line writes in both documented rising-edge modes 0 and 3. IDF S3 `clock_output_edge` encodes the output edge rather than CPHA; idle high/output low is mode 3. Modes 1/2, wrong CS/data/clock, reset and format constraints remain enforced.

Three targeted tests pass, including real green GRAM-to-framebuffer pixels during full-duplex writes in modes 0/3 on all three profiles, and negative mode/pad cases. Clippy with warnings denied passes. Source PDF bytes and the fixed IDF header are retained with their actual acquisition receipts; the already-retained VW source is referenced without duplicating it.

Two original complete factory images were rerun through the real S3 ROM for 5 guest seconds. LCD1.9 emitted 63 selected mode-0 transactions, 108800 written pixels, four RAMWR frames, a white final frame and a mounted 64MiB card. LCD1.3 emitted 24 selected mode-0 transactions, zero written pixels, one RAMWR command, a black final frame and a mounted card. Both had zero rejected transfers, zero full-duplex transfers and zero read transactions. This correction therefore does **not** explain their original bounded-run monochrome results. The actual unchanged results, UART and original frame bytes are preserved rather than relabelled as successful complete applications. Physical and complete-application validation remain false.
