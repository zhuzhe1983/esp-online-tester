# 五款经典 M5Stack 产品补充

本批新增五个由官方商店 SKU 明确区分的条目。EOL 仅表示厂家停售，不将其作为重复产品删除。

| SKU | 条目与硬件依据 | 运行边界 |
| --- | --- | --- |
| K002 | Gray；16MB 规格配置、MPU6886+BMM150、320×240 ILI9342C；独立官方文档提供 LCD/按键/TF 引脚 | 复用现有 Basic 显示、三键和 SD-SPI 子集，未模拟九轴传感器 |
| K001-V26 | Basic v2.6；16MB、CH9102F、110mAh；与 v2.7 保持独立 | 按独立文档核对相同数字接口后复用 Basic 子集 |
| K001-B | Basic COMM Edition；官方商店说明技术细节与 Basic 相同，透明塑料外壳 | 仅复用 Basic 数字子集；精确 SKU 文档入口 404 保留，没有继承出厂固件身份 |
| C001-CNC | Core Metal；官方 16MB、铝合金外壳、LCD/三键/TF 引脚 | 复用 Basic 数字子集；金属结构、物理装配与电源未验证 |
| K049 | 第一代 Paper；16MB+8MB、IT8951E、GT911；独立商店和文档 | 仅外观与资料预览，板级运行未实现，与 K049-B 分开 |

四款 Basic 家族型号保留原厂 K001 的外框、玻璃和按键网格，完整原始 STL、已装配网格、源变换与 SHA-256 随模型计划保留。它们是有明确来源的家族几何；本批没有声称找到这四个 SKU 的独立完整 CAD。底部盖板按各 SKU 官方尺寸和照片近似，隐藏的孔位、壁厚和结构没有猜建。K001-B 采用透明壳展示，内部 PCB 仍明确为 `UNKNOWN`；C001-CNC 的金属 PBR 参数只代表展示效果。四款屏幕始终使用模拟器 framebuffer，原始照片仅作为参考。

第一代 Paper 仅复用 K049-B 的两个外壳网格作为尺寸一致的家族近似，保留原位且不拉伸。它使用自己的官方 K049 背面照片和纸贴遮罩，避开复位键旁的机械细槽，不能混用 v1.1 的纸贴或固件身份。

官方资料存在冲突，均保留在各产品的知识和限制中：Gray 描述曾写 4MB，而规格表列 16MB；Core Metal 的商店/文档尺寸厚 18mm，而宣传图写 12mm；Basic v2.6 的规格厚 17mm，宣传图写 18mm。这些条目采用规格表作为配置依据，没有通过拉伸厂家网格制造通过结论。型号对应、后盖近似、纸贴位置和未独立校准的视角均需后续照片叠图验收。

五款都完成了官方出厂、恢复和开发入口调查；公开 M5Burner 的 Core Series/Paper 类目查询与 UIFlow、小智检索记录单独保存。类目和项目名称不能证明精确 SKU 映射，因此没有给新条目附上未核实的 BIN、版本或校验值。新目录提供各自的官方资料参考项及源码 watchlist，不继承现有 Basic/Paper v1.1 的出厂角色或通过结论。K049 文档链接中的程序标题还包含“v1.1”，该差异不会被抹去。

可复现命令：`python tools/build-m5-classic-expansion-models.py --output /tmp/m5-classic-rebuild`。生成器只读取已保留、hash 匹配的来源；输出绑定最终几何/模型 hash，不访问网络或下载固件。`node tools/platform-m5-classic-expansion-test.mjs` 检查五款实际加载、全部资产哈希、十二个真实 CAD 键面射线命中、材质隔离与展开复位。JSON/schema、知识引用和现有 Basic Rust 行为测试另行执行。

本批没有执行官方固件、实机刷写、同视角照片叠图或浏览器三种材质验收。模型尺寸误差与可见细节边界不以静态加载检查替代。
