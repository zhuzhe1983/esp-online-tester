# 外壳皮肤与本地贴纸

外壳的「展示预设」提供幻彩钛、深海钛、玫瑰钛、原钛拉丝、海蓝阳极金属和珍珠陶瓷，保留原厂外观、黑透、紫透和金色。多彩钛使用随位置变化的展示氧化色、程序化细纹及 Three.js 物理薄膜干涉；转动模型时反射色会变化。这些是查看器材质近似，不代表厂家提供的材质或实测光学参数。皮肤只改变外壳，屏幕、按键、接口和原厂标识保持自己的材质；恢复原厂外观也清除薄膜效果。

颜色、不透明度和材质沿用 `scene.view.appearance.shell`，可通过分享链接及 mini 页面还原。`iridescent-titanium` 是新增的 `finish` 值，其余字段和场景版本不变。

在「我的贴纸」中可一次添加多张 PNG、JPEG、WebP。选择一张后，轻点可见外壳或原厂外侧纸贴以放置；拖动仍可旋转设备。支持重新定位、大小、旋转角度及两个方向的微调，并可逐张删除。贴纸投影裁切到实际三角面，保留几何孔洞；承载面有透明遮罩时还沿其 alpha 裁切。屏幕、按键、接口和 UNKNOWN 占位文字不能作为贴纸承载面。贴纸跟随所在零件展开，且不会改变固件输入命中、镜头取景范围或原始 CAD。

图片和放置状态按具体产品 ID 保存在浏览器 IndexedDB：每款设备最多 32 张，原图每张不超过 12 MiB，解码后不超过 64 M 像素，处理后的最长边不超过 1024 像素，总量不超过 48 MiB。保留透明通道，不上传到服务器，也不进入场景 JSON 或分享链接。删除会先完成本地存储事务，再移除列表项。调整时显示保存状态；存储不可用或超出浏览器配额时明确提示仅在当前页面保留，切换设备仍保留该页面的临时副本。

贴纸属于展示功能，不证明产品硬件或固件兼容性。模型更新后如果原承载零件 ID 不再存在，保留图片与记录，可重新选择位置；不会自动贴到另一零件。透明壳体下用户贴纸保持自身不透明度。投影适合局部表面，大幅移出承载面后会被裁切，可用「重新定位」选择新的面。

验证：

```sh
node --test tools/platform-sticker-test.mjs tools/platform-scene-test.mjs tools/platform-config-test.mjs tools/platform-view-test.mjs tools/platform-manufacturer-model-test.mjs tools/platform-papermono-lite-model-test.mjs tools/platform-cores3-front-test.mjs
```

浏览器需检查批量上传、可见表面放置、旋转/缩放、跨产品隔离、刷新恢复、删除后立即刷新、多个贴纸叠放、窄屏面板和图片不进入分享。几何测试分别验证外壳反面排除、三角面缺口、UV 映射及原始网格不被改写；它们不是图片内容审核或物理材料测量。
