# Stamp-S3 S007：适配检查点

当前为研究与原生探测阶段，公开目录仍未启用，不计作已交付运行适配。

官方产品页明确 ESP32-S3FN8、8 MB Flash、GPIO0 用户/下载按键和单颗 WS2812B-2020。V0.2 原理图的 SK_DIN 接 GPIO21，按键经 10 kΩ 上拉、按下接地；GPIO46 默认下拉。固定 `m5stack/STAMP-S3` 提交 `6b64d431f930ff5e2bd770a07003ac983c24bc3f` 的 LED 例程同样使用 G0、G21、GRB 顺序，按键切换 Rainbow/Red/Green/Blue。该仓库示例不是可证实的出厂恢复镜像。

本轮实际下载固定官方 UIFlow2 v2.5.3 项目 `1897200000000000020` / 版本 `2098280680509362178`。镜像 8,384,512 字节，SHA-256 `6e3b8a72ab7c0d46de2cc661cc2c47e178621161fc29fa34f6d0313fd7037d72`。原生真实 ROM 启动到 20 客体秒，G21 接收到 4 帧 RMT，最终 RGB `[0,0,255]`；存在 I²C 端口未初始化日志。尚未验收浏览器、按键行为或联网，不把亮蓝灯称为整机兼容。

来源时间、最终 URL 和摘要见 [来源收据](evidence/stamps3/sources.json)。原始厂家二进制仅在 ignored 测试目录，网站仍使用远程链接。当前官网仅链接 Arduino LED 源码与 UIFlow2，未发现可直接认定的出厂 BIN；后续补查 Burner 历史条目，不将 UIFlow2 冒充出厂固件。

后续：完成板级 G0/G21 定向输入输出测试及 UIFlow2 实际 worker 启动；根据官方照片与现有厂家机械 CAD 标注盖板按键/灯孔，检查实际射线命中与客体灯色；全部 CI、浏览器、CPU 回归后再启用目录。模拟电源、FPC 屏幕、网络、GPIO 软件灯波形均不纳入本轮已验证范围。
