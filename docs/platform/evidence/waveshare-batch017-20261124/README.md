Five listing families: C6 LCD1.9 (touch and non-touch), C3 LCD0.71 (bare and protective-case option), C6 LCD1.47 (bare/header), C6 Zero-B (bare/header), and C6 Zero (bare/header). Ten actual sale SKUs produce twelve explicit profiles because the current C6 Zero overview specifies FH8/8MiB while the retained earlier schematic labels FH4/4MiB. No new sale SKU, undocumented revision name or hardware launch date is invented.

Release native regressions pass 26 C6 and four C3 tests. They exercise physical GPIO/mux/CS routing, source-specific panel formats, reset, exact SD MISO and card selection, correct RGB/BOOT, wrong routes, actual RV32 SRAM execution and package/eFuse capacity fields. Production WASM is rebuilt and four exact-capacity/chip/revision public registry gates pass.

A separately authored SRAM diagnostic runs through the actual public runtime and production Worker/WASM for C6 Zero FH8, Zero FH4 and Zero-B. It writes real GPIO/RMT/UART registers, emits the expected GRB-to-RGB values, produces new UART responses on BOOT press/release and restarts with the same image. The fixture has its own explicit diagnostic app descriptor and a normal image checksum/SHA; it is not manufacturer firmware. The original configured C6 ROM is used by the existing app-direct loader. No board spoofing or relaxed image validation was added.

Four unchanged manufacturer images run for5.02–5.08 guest seconds through the same public Worker. Full UART, raw RGBA, exact image/ZIP-member hashes, actual WASM hash and observations are retained.
