# TriviaPOD live display surface and input checks

The official source meshes remain unchanged: six parts, 81,532 triangles, geometry SHA-256 `f5db9047b3d85bf54e3ece5aa621ae2740af1a1cc35902152511c2e3f4e48e6b`. `build-triviapod-model.py` now declares a circular live display and maps the original blue/green button meshes to the compatible simulator's A/B controls. The red power button has no GPIO action and no missing expansion connectors are added.

The [official product page](https://docs.m5stack.com/en/core/TriviaPOD) specifies a nominal 1.75-inch round panel. Its 44.45 mm diameter fits inside the source's roughly 49 mm cover glass; the outer black border remains visible. The screen center follows the glass symmetry, with a Z=7.78 display overlay just above the source maximum Z=7.75. At the tested near-edge radius 22.18, the planar overlay is 0.05765–0.05807 source units above the curved glass. These are inferred model units and a rendering approximation, not measured physical panel geometry. The retained official photo 08 was visually checked for the inner display/border relationship; no product-photo pixels are used as framebuffer content.

`verification.json` binds the checks to final source hashes. Headless Chromium used the production manufacturer loader and scene input router. All 384 near-edge samples were visible from front, oblique and near-side views; 128 outer-border samples still hit the original glass. Both colored button meshes have exposed hit surfaces. Real pointer clicks produced paired A/B press/release events; 3D dragging produced touch down/move/release, with the center mapping to (234,233) in the 468×466 framebuffer. The 2D circle rejects its bounding-box corners, and visual-only mode emits no input.

The screenshots show a clearly labelled diagnostic color pattern, **not firmware execution**. Actual guest output and compatibility are verified separately by the integrating runtime change. No physical hardware was tested. The original independent-model, material, license, unknown internal PCB and source-unit limitations remain applicable.

To reproduce, build with Python 3.14 and NumPy 2.4.6 into a scratch directory; all nine retained model assets compare byte-identically. Serve the repository root, open `tools/fixtures/triviapod-runtime-model-review.html` in the Playwright wrapper, then run `tools/fixtures/triviapod-runtime-model-check.js` through `run-code`. Close the task-owned browser afterward. The fixture checks geometry and event delivery only and contains no firmware binary.
