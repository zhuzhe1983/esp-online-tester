# Waveshare batch 013 integration evidence

Five new listing families, 11 exact SKUs/profiles. Catalog, per-product knowledge, watchlist, source firmware identities, actual native tests and public Worker trials are retained separately.

The public original-image trials do not establish complete application support: DualEye and LCD3.16 remain single-color after five guest seconds; Knob displays a dim upside-down clock. Native 4B exits on the unavailable QMI8658 identity path; 7B LVGL exits at the missing ADC function. The source binary bytes were not altered.

Twelve prior/current photo-derived solid envelopes are corrected to hollow side walls, front optical annuli and independent rear caps. Manufacturer printed exterior dimensions are retained. Unannotated 1.5 mm walls/caps, openings and splits are explicit visualization estimates. The hidden PCB remains UNKNOWN. Original source images are unchanged; 11 contour overlays, assembled and expanded geometry views and actual Three loader cavity/input/shell-isolation checks are retained. Black Knob has no separate black front photograph. `before-hollow-repair` is historical evidence, not the current model.

The shared C6 PWM correction uses the documented duty field. `c6-touch147-pwm` reruns the unchanged original ROM using the rebuilt production WASM; the historical white-band repair remains effective.

These checks do not assert browser DOM/WebGL, physical assembly, radio, audio or full factory acceptance.
