# CloudZao Claw4 接入范围

本条目的主控是 **ESP32-P4**，ESP32-C5 仅为 ESP-Hosted SDIO 无线协处理器。原品牌名 Metalio Claw4 保留在别名和原始资料中。硬件知识、官方固件目录、外观预览与板级执行分别记录。

## 可使用的内容

- 独立产品 `cloudzao-claw4`、720×720 原生比例显示区、硬件知识和官方来源收据。
- 按官方正反面及斜视产品图制作的银色边框、黑色盖板、右侧金色电源键、后摄像头和独立背面印刷层。
- 可展开并复位的查看分组，以及带 `UNKNOWN` 的主板占位层。展开距离是查看安排，不是已证实的机械装配关系。
- microSD 接口声明使平台准备默认 64 MiB FAT32 本地镜像；该设备没有客体挂载链路。

## 当前不能承诺的内容

`runtime.board` 为 `null`，`runtime.status` 为 `unavailable`。当前 P4 内核对 DSI 地址仅有未实现外设名称，没有 Claw4 所需的 MIPI-DSI 寄存器、DMA 和帧输出链路。Waveshare 的 SPI LCD 模型不适用于本板，不能通过换板名使官方界面运行。

触摸、TCA9555、P4/C5 双芯片通信、摄像头、音频、GPS、Qi、4G 和电源 IC 尚未进行本板运行适配。现有在线刷写策略同样未开放 ESP32-P4；登记官方镜像与烧录资料不代表在线刷写通过。用户仍可使用厂商提供的工具，硬件刷写由厂商流程决定；本轮未刷任何实体设备。

## 固定源码与硬件版次

资料固定到 [CloudZao/MetalioClaw4 ca3aa3fa](https://github.com/CloudZao/MetalioClaw4/tree/ca3aa3fa027ff7dad2adf0c2d03c4f24aa838950)。原始 README、config.h、板级初始化、sdkconfig、LICENSE 与两幅产品图保存在本设备资产目录，实际抓取时间、字节数和 SHA-256 保存在知识记录和 `sources.json`。

默认 `METALIO_CLAW_4_USE_FL7707N=0` 选择 NV3051F / TRULY HE396-040T2BZZ。源码中的 FL7707N 是另一个备选面板，不能合并成“同一屏幕已验证”。还存在以下资料差异：

| 项目 | 资料 A | 资料 B | 处理 |
| --- | --- | --- | --- |
| P4 主频 | README 480 MHz | sdkconfig 360 MHz | 保留两值，不断言所有出货硬件的频率 |
| 像素位宽 | config.h 宏 16 | NV3051F 初始化 24 bpp | 默认屏按实际初始化记录；两处都保留 |
| DPI 时钟 | 初始化附近注释 36 MHz | 代码赋值 48 MHz | 记录冲突，不据注释构造总线 |
| GPIO53 | USB_CHG_STA_PIN 宏 | C5 SDIO D3 配置 | 不猜测是否为未使用宏或硬件版次差异 |
| SDMMC 引脚 | config.h 给出 GPIO43/44/39–42 | 同文件要求对照实际原理图 | 作为源码配置，未声称实机确认 |

统一固件目录选用的固定发布版本，与此处最新源码快照是两个独立身份；不能因为代码较新便把其硬件行为当作旧发布镜像的行为。

## 模型来源与精度

本轮检查官方仓库和产品资料，未取得匹配的机械 CAD、板级 STEP、KiCad 布局或 Gerber。官方产品图包含正面、背面及斜视，但未独立确认是实拍，按**厂家宣传图**使用，不作为实物量测。

README 仅给出约 80×80 mm。模型采用这一近似平面尺度，主体厚度 10 mm、盖板厚度、按钮突出和镜头深度均是明确的展示估算。屏幕的 70.9440 mm 方形边长来自 3.95 英寸名义对角线。宣传图的屏幕与整机比例和这一名义组合并不完全相符；保留差异，未拉伸模型以制造对齐。没有完成 1:1 实物验收，模型不可用于制造或校核装配间隙。

USB 插口保留中空凹部，但精确插座型号、完整线序、插入深度未知，因此不创建可连接线缆锚点。microSD 与 SIM 的实物开口位置未证实，不补造外壳缺口。扬声器仅近似可见格栅区域，不编造孔数。内部主板是空白 `UNKNOWN` 层，不使用原理图去猜测芯片位置。

背面标志从原始图的可见白色印刷独立提取透明 alpha，裁切和阈值在模型计划中。黑色玻璃与反光不变成纸贴，产品图的屏幕内容不覆盖显示表面。厂商图片、商标与衍生印刷保留原作者权利；原始仓库 MIT 许可保留，未额外宣称图片和商标授权。详见资产目录 `NOTICE.md`。

## 重建与检查

```sh
python tools/build-cloudzao-claw4-model.py --output /tmp/cloudzao-models
node --test tools/platform-cloudzao-claw4-model-test.mjs
```

重建只读已保留且哈希匹配的来源，不联网；输出几何、模型、logo 与导出收据已进行逐字节复现对比。产品与知识 schema 检查通过。实际通用 Three.js 模型加载、`UNKNOWN` 元数据、展开复位、金色/紫色外壳不影响玻璃/按键/印刷等检查通过；图片解码和本地文件获取使用测试替身，不把这些 Node 结果描述为 WebGL 截图验收。

本环境的 Chromium 在打开页面前因 socket 权限退出，因此真实浏览器视觉验收仍未完成。保留 `tools/fixtures/cloudzao-claw4-model-check.js`，可在本地合并后按仓库 Playwright 工作流运行。正反面、侧面、原色/金色/紫色与展开后的 `UNKNOWN` 可读性仍须真实浏览器复核。证据状态和本次最终资产哈希在 `evidence/cloudzao-claw4/checks.json`；未进行固件执行或实体设备测试。
