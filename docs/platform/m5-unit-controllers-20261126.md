# Five independent M5Stack Unit controllers

This batch adds exactly U082-X TimerCamera-X, U120 Unit LCD, U139 Unit ACSSR, U140 Unit DCSSR and U149 Unit Thermal2. All five remain `runtime.status: unavailable`, `board: null`. No camera, thermal frames, relay, LCD drawing, RTC, power circuit, RS485, wireless transport or audio execution is claimed. These are CAD-backed previews and product/firmware investigations.

Sources are pinned to `m5stack/M5_Hardware@18de3bb3087ea617c38642ba3eedd10dc9f17cbf`. TimerCamera-X's folder uses nonbreaking hyphens (`U082‑X_TimerCamera‑X`); searching ASCII SKU text alone misses its actual original STL. Selected source component numbers, rigid matrices, omitted components, input hashes, dimensions and every perspective crop are retained in each `assets/<id>/model-plan.json`. The source MIT license is included. Manufacturer photographs retain separate copyright; no open-photo license is inferred.

All five contain an explicitly estimated UNKNOWN PCB. Source structures provide enclosure geometry, not a populated PCB layout. Optical/terminal/fork depth and connector internals are independently tagged estimates. Open Grove/USB housings are visual only; no mating orientation or cable wiring permission is asserted. TimerCamera-X's own rear label reads `G,V,SDA G4,SCL G13`; cable colors are left unknown. Visible mechanical hardware was audited in knowledge records: Timer-X has two rear screwheads; LCD/Thermal2 have a central rear screwhead and two circular mounting seats. Their separate installed screws/magnets are not reconstructed, and hidden lengths remain unknown.

Printed paper has independent material and full effective-alpha masks. A separate0.01mm display paper sheet plus0.005mm image-face separation explicitly describes the rendering estimate, not measured paper or adhesive stock. Native plastic support is never invented. LCD/SSR photographs show continuous labels over native slots/open areas, so the actual printed regions are not blindly clipped to the cavity floor. `paper-support.json` checks all1,473,376 effective-alpha pixel centers, including local back-face X reversal. All six printed faces have carrier support and no case intersection at their image planes. Native-case depth distributions are retained rather than collapsed to a bounding rectangle. These checks cannot establish physical paper thickness or deformable-paper contact.

Original, gold and translucent-purple material isolation is exercised using the real Three model loader. Paper, optics and connectors stay separate. UNKNOWN center visibility is tested through the translucent case for Timer-X/LCD/Thermal2, and after opening SSR button covers from a recorded oblique direction. This is a center-ray check, not rendered text-legibility acceptance. Each source assembly returns to its exact starting positions after three expansion/reset cycles. Paper moves with its actual enclosing shell; estimated soldered ports/forks remain with the estimated board assembly.

Firmware identity is separate from appearance. The exact Timer-X product page links `TimerCam-idf` as FactoryTest; its fixed source tree and README's successor `M5_Camera_Examples` contain source programs, not a proven boot package. The linked Windows EasyLoader is recorded without pretending it is a verified raw Flash image. The official UIFlow guide explicitly distinguishes TimerCam factory behavior from its UIFlow camera firmware. Public TimerCam's device category also contains PoE/UnitCam/CamS3 projects, so a family category alone is insufficient to assign their image to X.

The LCD internal repository has `examples/FirmwareUpdater/firmware.bin`; Thermal2 has an official V0.7 candidate named `...-0x0.bin` and FactoryTest source. Neither filename nor Git blob SHA proves the Flash layout or SHA-256. They remain references with no executable source until their complete boot package/layout is established. ACSSR/DCSSR product-linked `M5Unit-ACSSR` is a host Arduino control SDK, not internal controller factory firmware. No host example or generic MicroPython image is substituted for a unit's own firmware.

The UIFlow keyword query returned75/75 records and 小智 returned16/16; selected public project/device fields and original response hashes are retained. No exact current-five official internal image mapping was found in those bounded searches. Fifteen manual watch entries are `reference-only`, all execution/hardware verification flags remain false, and no binary was downloaded or mirrored. Each product has its own explicit factory investigation outcome and source revision.

Evidence is in `docs/platform/evidence/m5-unit-controllers-20261126/`. Schema/unique IDs, actual knowledge constraints, watchlist validator, catalog loading/selection, manufacturer loader, config, input and view tests passed (18 Node subtests across eight files).
