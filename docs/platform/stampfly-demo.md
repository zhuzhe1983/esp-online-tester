# StampFly 网页飞行演示

StampFly 与 StampFly v1.1 都可使用独立的 **UART 遥控演示 · 0.1.0**。它执行真实 ESP32-S3 固件，通过 UART 接收指令、SPI/I²C 读取传感器、LEDC 控制电机。产品默认仍是对应型号的官方出厂固件。

## 网页操作

1. 选择 StampFly 或 StampFly v1.1，在固件列表选择「UART 遥控演示 · 0.1.0」，点击运行，等待演示固件就绪。
2. 只看螺旋桨时，点击「四桨 20%」或调整四个滑块并应用；下方「实际 PWM」来自客体外设输出。
3. 要飞起来，先暂停，展开「近似物理飞行」，点击「启用飞行环境」，再运行。更改环境会重启客体，电机从零开始。
4. 设置目标高度，例如 0.35 米，点击「起飞并保持高度」。高度、姿态及接地状态来自 PWM 驱动的动力学模型；固件通过模拟传感器反馈控制飞行。
5. 飞行中可修改高度、横滚、俯仰和偏航角速度，再点击「应用目标」。横滚或俯仰会造成水平移动；没有水平定点功能。
6. 点击「降落」下降；「停止」直接将电机 PWM 归零，空中的机体会落下。暂停会冻结固件与物理状态；暂停时「停止并复位」重新启动固件，恢复地面和零输出。

分享保留选定固件和是否开启环境，不保留空中位置或起飞指令。接收方从地面开始，需手动起飞。此模式暂不支持录制回放。

这是未经实机标定的演示：理想电机、固定电压、平地接触及简化传感器光学不等同于真实无人机。当前没有光流定点、磁航向、气压计、风、障碍物碰撞或 ESP-NOW 遥控链路。完整依据与时间步长见[飞行环境](stampfly-flight.md)，固件指令与源码见 [UART demo](../../firmware/stampfly-uart-demo/README.md)。

## 真实设备的官方途径

M5Stack 官方方案使用 M5Burner 的 StampFly Firmware 和 StampFly Controller Firmware。按[官方固件指南](https://docs.m5stack.com/en/guide/stampfly/firmware)给对应设备安装固件，控制器进入配对模式后重启飞机完成配对；控制器中央按键用于起飞和降落。飞机的 G0 按键是复位/配对入口，不是网页起飞键。Atom Joystick v1.1 需核对指南中的控制器固件版本要求。

硬件 v1.1 与固件版本号分别记录，不应因名称相似互换镜像。本项目没有替你刷写硬件，也没有进行实机飞行验证；网页 UART 演示不替代官方遥控固件。
