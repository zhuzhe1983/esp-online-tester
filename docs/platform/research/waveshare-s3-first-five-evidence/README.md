# First five S3 families: explicit acceptance layers

The native Rust unit logs exercise guest-visible protocol outputs and negative routes, not just registration. RGB Matrix is a standard two-row one-bit diagnostic and does not claim complete PWM colour or B/F scan-map support.

AMOLED2.06 original manufacturer image was executed from ROM for eight guest seconds with zero reboots;603 RAMWR operations/2439020 pixel writes and no rejected QSPI transaction were observed. The image remained unchanged from four to eight seconds. This confirms initial display output, not complete application interaction, RF, audio or physical hardware. Unchanged observed captures are retained here.

No hardware was connected. Browser/worker checks are separate from these native results. Manufacturer source files and original binary hashes are recorded in docs/research/waveshare-s3-20261123 and docs/research/waveshare-amoled206-sources. Binaries are remote links only.
