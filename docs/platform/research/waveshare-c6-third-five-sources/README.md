# Exact official third-five electrical sources

`manifest.json` records108 original source bodies or binary source receipts for the five listing groups. Non-binary original bodies are retained as deterministic gzip with both compressed and original hashes. Binary images remain remote links only. Selected documents include both GEEK schematics and SD revisions, exact LCD1.3 archive members, AM18 V1/V2 driver/pin definitions, LCD1.83 Rev1.2 schematic and exact display program, and AMOLED1.32 factory board/LCD/touch/codec code.

Git files were fetched from fixed official `waveshareteam` commits. LCD1.3 has no asserted Git repository; its published Demo/Structure ZIPs are recorded as containers, and extracted members retain independent byte count/hash and original container hash/path. A derived archive inventory or Git tree is labelled derived; it is not represented as raw HTTP response content.

Mechanical source manifests, unchanged photos and complete pinned repository-tree/CAD search evidence reside with the6 model assets. Anonymous storefront session HTML is not committed; public selected SKU data is explicitly labelled derived.

Source conflicts and current runtime failures are retained in the batch evidence and product knowledge. Public availability does not imply an MIT licence for upstream documents, CAD, images or firmware. Their original rights remain with their respective owners.
