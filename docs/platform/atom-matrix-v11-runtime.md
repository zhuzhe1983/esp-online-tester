# Atom-Matrix v1.1 C008-B-V11 适配记录

本阶段按该版官方资料单独实现 `atom-matrix-v11`：经典 ESP32-PICO-D4、4 MB Flash，G39 按键、G27×25 RGB，以及 SDA25/SCL21 上的 BMI270 `0x68`。不能沿用旧版 MPU6886 的寄存器。原始 UIFlow2 v2.5.3 镜像已在原生 ROM 启动到 MicroPython REPL，实际 RMT 输出为25颗蓝灯；浏览器与输入验收仍在进行，暂不宣称完整功能兼容。

官方 v1.1 产品页明确链接共享 Atom-Matrix UIFlow1/2 教程。固定 M5Burner UIFlow2 项目 `2099000000000000002`、设备 `2093000000000000009`、版本 `2098279897621549057`；原始镜像4,186,112字节，平台计算 SHA-256 `1591382c9b46f10549faa0053b4036aa55f5c8131867b2f039d2650982e7886d`。资料、原理图、轴向图与链序图的抓取时间和 hash 见 [sources.json](evidence/atom-matrix-v11/sources.json)。无固件二进制入库或发布。

当前调查未找到明确用于 v1.1 的官方出厂镜像，也未确认该具体版次的小智项目；默认选择 UIFlow2，角色保持 alternative，不把它冒充出厂固件。旧 C008-B 出厂镜像没有自动加入此版。UIFlow1 保留试运行，本轮未执行。

BMI270 沿用 Bosch DS000-08 的现有数字轮询子集，初始化要求完整8192字节配置写入；不执行特征代码，不模拟 FIFO、中断、采样时序或物理噪声。硬件与软件位操作 I²C 共用器件，硬件路由限于真实 SDA/SCL。红外、模拟供电、真实 Wi-Fi/BLE、Grove外设均未验证。原生官方固件仍有 XTAL估计和 I²C未初始化日志，保留限制。
