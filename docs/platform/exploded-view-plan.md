## 第一版的表现

1. 沿用厂家壳体与独立按钮帽，保持现有原始坐标和来源。壳体连成一个网格时，不依据猜测切成前后盖。
2. 补 `pcb-main` 空白占位板，板面正背标注 **UNKNOWN**，外露连接器依据照片和现有锚点摆放。无依据的芯片、走线、焊盘、丝印和螺丝孔不绘制。
3. 没有板形尺寸时，允许以壳体内部空间为约束估算。首版暂估圆板直径 44 mm、厚度 1 mm、中心 `(0, 0, 0)`，均为展示占位，不是测量结果；取得实证后替换。
4. 屏幕现有可见面继续使用真实 framebuffer。其可视面不等于已核实整个屏幕模组的厚度；电池、扬声器等内部零件若没有位置依据，不伪装成精确装配。
5. 外壳可选原色、黑透、紫透、金色，以及自定义颜色、不透明度和表面效果。仅改变外壳材质；自定义金色不代表厂家提供金属版本。透明视角下占位状态仍可识别。

## 查看器与 onboarding 的分工

查看器负责展开滑杆、动画、选择零件、标签、复位和镜头适配。onboarding 负责零件可独立拆分、原位变换、局部分离方向、装配层级、连接器锚点与来源等级。两者共享语义零件 ID。

建议为资产增加可选的装配描述，包含 `id`、父零件、几何节点、原位变换、来源引用、`fidelity`（厂家 CAD / 照片估算 / 占位）、局部分离方向和距离。该描述是待落地的数据设计，不是已经发布的 agent API。坐标统一用产品局部毫米，glTF 导入显式从米换算。

使用 `position = originalPosition + direction × distance × amount`，其中 `amount` 范围为 0–1。每帧从原位计算，避免累计误差；装配子件继承父组位移，不能重复相加。方向由入库数据确定：主板和屏幕沿厚度分层，按钮向外，中心径向发散只能作为编辑器建议。

## 实施顺序与验收

**阶段一：零件和来源。** 完成稳定 `pcb-main`、按钮、壳体、屏幕与端口标识；保存厂家部件、估算几何及 UNKNOWN 占位的区别。半透明材质、换色、分享和 mini 页面先使用这些数据。

**阶段二：爆炸查看。** 增加展开程度、复位和零件信息。进入拆解检查时释放按键/触摸，并暂停正在运行的固件；退出后由用户继续运行，避免拆开状态下误操作。配件可整体保持连接，或清晰显示拆开的插头，不能画成仍连着的悬空线缆。展开只改变展示变换，不改变电气配置。

**阶段三：分享与 agent。** 在版本化 scene 的展示配置中加入可选展开状态，限制数值范围；独立页面和 iframe 使用同一控制实现。给 agent 增加经过验证的设置/观察接口，再更新操作 skill；录制行为默认仍只包含固件输入，不混入展示动画。

**验收重点：** 原位零件重合与尺寸对照、展开层次可辨、UNKNOWN 在占位板上可读、端子随正确部件移动、多次展开复位无漂移、透明排序及遮挡、外壳变色不改屏幕、2D/3D 切换与分享还原。1:1 外观照片验收使用原始材质。占位板的内部尺寸与布局列为未验证，不因外壳轮廓通过而改判。

## 得到 PCB 数据后的升级

最有用的是对应硬件版本的板级 STEP（含元件）和装配图。其次是 PCB 工程，或 Gerber + 钻孔 + BOM + 贴片坐标 + 板厚；只有 Gerber 仍不足以确定全部元件高度。无工程文件时，可用带比例尺的正反面拆机照片及板厚/层间高度实测，保留估算状态。

用新几何替换 `pcb-main`，移除对应 UNKNOWN，保存旧来源与替换记录。保留兼容的零件 ID；若新尺寸改变端口位置或层间关系，则一起更新锚点、爆炸位移和配置版本，重新验收。无需重新开发整个查看器。
