# 查看器布局与全屏

「外壳」展开为独立编辑区：桌面在画布右侧，手机在画布下方。画布随可用空间重排，预设、颜色和多张贴纸不会再浮在设备上。编辑区单独滚动；「在模型上放置」会收起面板，便于点击承载面。

全屏优先使用浏览器 Fullscreen API，在不支持或被嵌入策略拒绝时留在当前页面、铺满可用视口。两种模式都保留正在运行的固件和设备存储，退出后恢复页面滚动与布局。iPhone 等不提供网页原生全屏的浏览器仍可能保留浏览器自身的地址栏，网页不能强行隐藏系统界面。

全屏中的「收起工具」隐藏工具栏、运行按钮和状态浮层，仅保留「显示工具」入口。画布使用动态视口和安全区域；手机支持双指缩放，第二根手指落下时先释放已有的固件输入，直到两根手指离开才恢复单指交互。桌面仍使用滚轮，恢复视角会复位缩放和旋转。

所有产品采用同一套取景算法：按可见实体的投影范围居中，并补偿透视下近远两侧的差异。旋转、编辑区开合、窗口缩放和全屏切换都会更新取景；隐藏辅助物、悬停轮廓和用户贴纸不参与取景边界。模型自身 CAD 坐标和固件输入坐标不变。

验证包括偏离原点的 CAD 在不同视角和长宽比下的投影居中、两指释放规则，以及真实 Chromium 中的桌面原生全屏、390×844 竖屏、横屏、全屏拒绝后的页内回退、Esc 退出、面板不重叠和 mini 页面。浏览器模拟手机视口与触摸输入，不等于已在所有实体手机浏览器验证。
