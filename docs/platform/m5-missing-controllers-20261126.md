# 五款遗漏主控的独立条目与模型

本批补入 K140 SwitchC6、K016-P2 StickC-Plus2、K117 AtomU、K126 T-Lite 和 U195 Unit Gateway H2。五款都有可追溯硬件知识、3D 外观和出厂固件调查；板级运行保持 `unavailable`，界面继续显示“尚未完成适配”。已有同系列设备的运行能力没有转移到这些新 SKU。

| SKU | 模型依据 | 固件调查 | 当前缺口 |
| --- | --- | --- | --- |
| K140 | 官方尺寸图、58×46×27 mm 参数与多视图照片；透明壳、DIN 底板、橙色扣件和独立纸贴 | 官网明确预装 ESP-NOW 程序；未找到可唯一定位的公开出厂镜像 | 继电器、电源、无线协议及内部布局未模拟 |
| K016-P2 | 官方 24×48×13.5 mm 参数、精确版本照片、背贴、独立按键和动态屏幕面 | 精确官方 UserDemo V0.1，默认第一项；另有 UIFlow2 v2.5.5 / UIFlow1 v1.15.5 | Plus2 取消 AXP192，LCD DC/RST、HOLD 与电源语义不同，未复用旧 Plus 板型 |
| K117 | 官方 20×53×10.3 mm 参数、USB-A、Grove、灰壳和独立背贴 | 官方 Arduino/UiFlow 资料；未定位精确出厂镜像 | PDM 麦克风、RGB、IR 和板级输入尚未模拟 |
| K126 | 官方 26.6×69×16.4 mm 参数、多视图照片、硅胶套、热传感器窗口与动态屏幕面 | 精确原版官方 T-Lite 0.0.13，默认第一项 | MLX90640、显示、AXP192 与业务功能未验证，不显示静态热成像照片 |
| U195 | 厂家 STL 原位装配件0/2；1/3 是平移打印副本；保留原始坐标、许可证及2个壳体分组 | 官方 UART/ESP-IDF/Thread/Zigbee 资料；未定位唯一出厂镜像 | ESP32-H2 运行、IEEE 802.15.4、Thread/Zigbee/Matter 和完整 PCB 尚未模拟 |

官方完整硬件树固定为 `m5stack/M5_Hardware@18de3bb3087ea617c38642ba3eedd10dc9f17cbf`，本次实际读取的 996 项没有截断。当前五款中，仅 U195 找到匹配的厂家结构文件；其他四款没有在这些已搜索的一手来源中找到 CAD，外观按照片和尺寸明确建成近似，不把近似几何称作原厂结构。

所有照片、尺寸图、原理图、官方商店与 Burner 元信息的实际 URL、UTC、字节数和 SHA-256 保留在 [sources.json](evidence/m5-missing-controllers-20261126/sources.json) 和各产品知识文件。公开分发的照片仍属于原权利人；U195 STL 的 MIT 许可证单独保留。图中的唯一设备 MAC 贴纸照片没有作为资产保留，固件 API 只保留脱敏的项目/设备/版本字段。

贴纸来自型号对应的照片，裁切点、透视矩阵、透明遮罩和最终 UV 放置均在 `model-plan.json` 中。纸贴是独立薄面，不将塑料、侧壁、镜头和屏幕一并烘焙到外壳。金色及紫透设置只改壳体材质；原有印刷、连接器、镜头和屏幕保持独立。Plus2 与 T-Lite 的屏幕只绑定模拟器 framebuffer，本批没有运行器，也没有用产品照片伪造运行画面。

尺寸分别保留“原生网格”和“包含派生物理件的完整装配”两种范围。以下完整装配测量使用实际 Three.js 对象，排除纸贴、文字、输入热点及 framebuffer 平面。照片重建件的局部尺寸仍是估算，数字接近不构成制造精度合格：

| SKU | 官方标称（按展示轴）mm | 当前完整物理装配包围盒 mm | 结论 |
| --- | --- | --- | --- |
| K140 | 58×46×27 | 57.90×46.00×27.00 | 图纸主体54×32，整体57.9×46×26.8；扣件隐藏深度仍为照片估算 |
| K016-P2 | 24×48×13.5 | 24.45×48.05×13.65 | 侧键和薄纸/插口位置近似，未通过1:1尺寸验收 |
| K117 | 20×53×10.3 | 20.00×53.05×10.51 | 官网旧宣传图写52×20×10，当前参数写53×20×10.3；差异保留 |
| K126 | 26.6×69×16.4 | 26.60×69.05×16.55 | 旧宣传图厚15.5，当前表格16.4；硅胶及窗口厚度为近似 |
| U195 | 24×48×8 | 24.00×48.02×8.19 | 原生壳体24×48×8吻合；派生可见螺丝/插口隐藏尺寸未获得独立标定 |

PCB 保留 `UNKNOWN`，不从原理图推断实际元件位置。U195 可分开查看壳体并精确复位，其他四款不编造未经证实的拆解层次。透明模式下 `UNKNOWN` 中心的视线通过实际模型射线检查，整段文字的浏览器可读性仍待复核。接口没有完整插合/逐脚朝向证据时，不显示已连接线缆；Unit Gateway H2 的内部 USB-C 没有被画成外壳外的端口。

可离线重建：

```sh
python tools/build-m5-missing-controller-models.py --output /new/scratch/directory
node tools/check-m5-missing-controller-models.mjs
python tools/validate-platform-catalog.py
node tools/platform-knowledge-test.mjs
```

重建需要 `tools/requirements-model.txt` 中的依赖。五款的原始输入均本地保留并先检查 hash，第二个独立目录生成的几何、纹理与 metadata 逐字节一致，见 [重建记录](evidence/m5-missing-controllers-20261126/rebuild-check.json)。真实 Three 加载、原生几何边界、纸贴材质隔离、透明壳下 UNKNOWN 中心可见、U195 展开/复位和完整装配尺寸结果见 [加载检查](evidence/m5-missing-controllers-20261126/loader-check.json)。这组 Node 检查读取真实资产，但图像解码使用替身，不冒充浏览器渲染或同视角照片验收。

目录/知识 schema、27 项配置与固件选择/目标/watchlist 回归已通过。无 Rust 或 WASM 修改，不涉及 CPU 性能结论；没有下载、执行、刷写官方镜像。原厂色/金色/紫透的真实浏览器截图、同视角叠图、嵌入/分享还原、官方应用行为及实机验证均留作未完成项。
