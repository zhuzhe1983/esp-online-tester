# 建模与 1:1 验证

## 来源和坐标

先寻找厂商结构文件，例如 M5Stack 的 `https://github.com/m5stack/M5_Hardware/tree/master/Products`。下载后列出网格连通分量及各自包围盒，依据图纸和照片确定装配关系。报告记录源提交、SHA-256、单位、旋转/平移、删减对象与原因。单个文件可能包括未装配组件，整个文件的包围盒不是整机尺寸。

平台现有 Three.js 场景以毫米工作；glTF 标准以米表达，导入时显式换算。只允许有依据的单位换算，不能非均匀拉伸来掩盖尺寸不符。保留外壳、玻璃、屏幕、按钮、连接器、磁铁等独立语义；屏幕材质取自模拟器 framebuffer。按键热点随模型移动。

标准零件使用具体厂商图纸或模型，保留许可。用 Type-C 等作照片比例尺时，要选同一投影平面的已知尺寸；远近不同或遮挡会使结果不可靠。没有独立尺度或视角依据时，记录估算和不确定性。

## PCB 占位、拆分与替换

缺少 PCB 布局/3D 数据时仍提供主板占位层，并显著显示 `UNKNOWN`。直接裸露的一面可使用同型号高清照片还原可见外观：先确认 PCB 底色，再校正透视、遮罩板形与孔洞，将照片贴到该面，`UNKNOWN` 放到另一未知面。已知立体器件、端子或连接器继续使用独立几何，不用照片把它们压平成板面。原理图中的芯片可以进入知识库，不能据此猜测它们在 PCB 上的坐标。没有照片依据的区域保持空白；板形或厚度不明时用适合壳体内部空间的简化形状，记录约束、估算值和缺失证据。

为主板保留 `pcb-main` 等稳定 ID，来源状态为占位，并保留装配坐标、连接器锚点和父子关系。`UNKNOWN` 是模型内标识，不是可覆盖固件画面的图片；应在展开、反面检查及透明外壳模式下可辨识。它与元信息中的未知状态共同存在，不能只在说明文字中披露。

新资料到来时优先用厂家板级 CAD 替换占位几何；否则使用有比例尺的板面照片和实测尺寸重建。保留兼容的 ID 与锚点；若实测位置与估算不同，更新依赖的连接器、爆炸位移及版本，并重新验证。记录占位来源被哪个数据版本取代，不能沿用占位模型的旧验证结果。

爆炸图保留原始装配变换，按明确的局部方向与距离分离装配组。中心径向发散只适合预览建议：屏幕、PCB 和电池可能同心，必须按厚度方向分层。连通网格不自动等于一个真实零件，打印排版重复件不算第二套零件。验证展开后标识与端子仍跟随正确部件、层间不重叠、复位无累计漂移。几何与来源没有支持的层次标为未知，不强行宣称完整拆解。

PCB 占位验收检查可辨识的 `UNKNOWN`、无虚构细节、外露端子位置、稳定零件 ID 和复位结果。内部尺寸与元件布局列为未验证；整机外观的轮廓测试通过不改变这个结论。

对照片覆盖的裸板，分别检查已知面、未知面和板边：实际 PCB 色与纹理底色应相符，不能由纹理透明区露出错误的占位色；照片不延伸到通孔内壁、侧壁或不同高度的器件；翻转或展开后能看见另一面的 `UNKNOWN`。原色、金色、半透明紫色下 PCB 与照片保持自身材质。报告逐面注明“照片外观”“占位未知”或“厂家板级 CAD”，不将照片覆盖升级为布局或电气验证。

`UNKNOWN` 必须在公开查看器提供的翻转、展开或透明模式中实际可读，保留完整装配截图及操作路径；仅隐藏遮挡件后拍摄的独立零件图不能作为通过依据。标识的中心和四角应落在实际承载面内，局部高度按该处 CAD 面核对，不能假定整块 PCB 或安装支架共用一个高度。检查电池、支架和螺柱遮挡，并在用户可达到的缩放范围内验收；不能靠悬浮文字绕过遮挡。

通用查看器的 `pcb-placeholder` 使用 `part.color` 声明板色，`geometry.labelSide` 指定 `UNKNOWN` 所在面：`front` 为局部 +Z，`back` 为局部 −Z，`both` 为双面默认值；方向按零件旋转前的局部坐标解释。这个字段控制未知标识，不控制照片面，也不允许隐藏所有未知标识。真实板级 CAD 不因缺少可编辑的 PCB 工程而另加占位板或 `UNKNOWN`。

有独立尺寸或照片依据的外轮廓与通孔可用 `pcb-placeholder.geometry.shape: "polygon"` 声明：`outlineMm` 为局部 XY 毫米顶点环，`holesMm` 为互不相交的孔环数组，厚度取 `sizeMm[2]`，Z 以零件中心对称。顶点不重复首点；边缘半孔或缺口写入外轮廓，完整通孔才写入孔环。相同轮廓可用 `kind: "plate"` 与 `geometry.depthMm` 制作独立薄纸面。两者均保留依据和估算说明，不能把外形准确等同于元件布局准确。`labelSizeMm` 可缩小 UNKNOWN 的局部宽高，但仍须验证文字清晰、实际承载面和孔洞避让。

## 外壳展示材质

可提供原色、黑透、紫透、金色等展示选项，并允许设置颜色和透明度。只修改外壳材质，屏幕 framebuffer、按钮标识和连接器保留各自材质。区分颜色、透明度和金属效果，不把金色预设等同于真实金属外壳。

查看器目前的表面类型包括哑光/亮面塑料、磨砂半透明、透明树脂、橡胶、金属、拉丝金属、陶瓷和多彩钛金属。这些 PBR 参数和程序化纹理只是展示近似，不是厂商材料数据；同一配色下应有可辨的表面差异，换材质及反复复位须释放独占资源，不能修改共用材质而误染按钮或屏幕。

材质设置属于查看器展示状态，分享链接和 mini 页面应能还原；它不修改产品事实或官方 CAD。原色复位须恢复完整材质参数。官方照片对照使用原色与默认透明度；透明或自定义颜色另验，检查透明排序、内层可见性、`UNKNOWN` 标识及悬停提示，不将半透明后可见的背面按钮当成前面的点击目标。

## 照片纹理

先目视原始高清照片，选择无强反光且无遮挡的区域。裁切、镜头/透视校正用确定性图像处理，记录原图 hash、像素坐标、输出大小与变换矩阵；照片来源和授权说明随衍生纹理保存。公开可下载不等于可任意再授权，不给厂商照片盖上本项目 MIT 标识。

贴图适合背贴、丝印、标识和表面细节；开孔、端口、按钮高度等重要轮廓用几何体。不要把照片的屏幕内容当作模拟输出。无法辨认的字和端口不凭空生成。

校正板面透视和尺寸时，沿 PCB 基材板边取界，用共面的已知尺寸或地标定位；插座、镜头等外伸轮廓单独量取，不能并入板长或板宽。可见凸起按有来源的 CAD、图纸或多视角照片建立独立几何；缺失高度逐项注明未知或估算，不套统一厚度。板面纹理遮掉这些已建模器件的投影，器件自身的纹理只贴对应表面，避免同一组件既印在 PCB 上又以立体件出现。

按纹理非透明区域检查承载关系，不能用整个矩形贴图的包围盒代替有效纸贴边界。贴纸先匹配实际纸边与印刷比例，再用遮罩避开孔洞、螺丝、螺柱和插口；各区域在同一高度面上才共用平面。纸边须按实物的支撑关系建立，贴纸与承载面仅保留防闪烁所需的小偏移。若独立照片明确显示纸贴跨过塑料槽口，应保留真实纸桥并建立独立薄纸面，注明该处没有塑料支撑，不能盲目沿塑料开口裁掉印刷内容；没有这类证据时不得用纸面补猜缺件。保留侧视和孔洞近景，检查悬空、穿透、背面透出与外壳改色后纸贴变色。发现承载面缺失时先补有依据的几何，不能靠放大贴纸遮住缺件。

## 紧固件与装配完整性

逐款列出照片、CAD 或装配图可确认的螺丝、螺柱、垫片和支撑件，核对数量、位置、头型、颜色及装配方向。缺件优先采用厂家或有尺寸依据的标准件；只能确定可见部分时，保留该部分并标注隐藏尺寸未知或估算。离体 CAD 零件先判别是打印排版、备用件还是未装配部件，不能直接移进空孔。

从正反面和斜侧面检查紧固件与实际孔位相合、头部未被贴纸覆盖、支撑件没有悬空或穿透 PCB；爆炸图按真实装配关系分组，复位后恢复原位。整机轮廓接近不能替代这项检查。无证据确认的螺纹、内部螺母和安装方向保留为未知，不以规则圆柱冒充精确标准件。

## 三种独立验收

**尺寸验收。** 建模前登记来源尺寸、单位和容差；官方标注作为目标，CAD 原值作为另一条证据，不允许用待测模型自己生成目标。比较整机外径/厚度、显示区域、按钮、端口和有明确标注的孔距。导出与源 CAD 的数值差控制在数值精度范围（默认 0.05 mm），与独立图纸的容差按图纸精度或事先说明的范围选取。照片推算不按制造公差合格处理。

补建排针、螺丝等 `derivedParts` 后，整机尺寸必须包含这些零件及其装配变换。当前 `onboard-lane-01.py` 的尺寸检查只汇总原生网格和导出表面，不能据此声称完整装配尺寸通过或失败；保留原结果并明确测量范围，另用实际查看器中恢复装配后的完整对象包围盒（如 Three.js `Box3`）对照独立图纸。报告绑定最终模型 hash，分别记录模块本体和包含排针、支架等零件后的外形，排除交互热点、文字标识等非实体辅助对象。不同 SKU 的针距、针座和露出长度分别核对，不按相近型号套用。

**同视角视觉验收。** 至少选择可获得的正面、背面、侧面/斜视参考，说明缺失视角。以已知外形定尺度，用与建模无关的照片轮廓和地标校准投影、旋转与相机，记录参数。提供透明叠图/轮廓差与并排图。比较轮廓、屏幕比例、按钮位置、端口、背贴、颜色与材质。拍摄透视和畸变不能通过拉伸模型修正。

对含可拆电池的产品，标明每张参考图与渲染中的电池是已安装还是已拆下；分开查看另记展开状态。装配对照使用同一状态，不能混用不同状态的参考来改变零件位置。正、侧、底面近景检查镜头、插座、电池与支架的遮挡、实际连接面，以及应有的接触或间隙；用 CAD 或同状态来源核对间隙，不能仅凭单一视角重叠认定穿插，也不能用悬空摆放掩盖干涉。

像素误差或轮廓 IoU 只辅助判断，须公开参考 mask/地标与计算方法并标注遮挡。不为高分忽略明显错误，不用同一 CAD 投影同时生成参考和待测结果。不能完成对齐就报告未验证，不宣称已通过“1:1”。照片验收说明可见外观一致程度，不证明内部结构或制造精度。

**功能验收。** 按键命中、按住/释放、键盘映射、触摸/滑动、2D/3D、配件装卸和缩放分别检查；输入回执只是排队，要进一步观察固件输出。共享及嵌入场景也要测。未实现的部件保留事实元信息，但在界面说明限制。

报告包括：被测资产 hash、来源与时间、尺寸表、相机/对齐参数、参考与渲染、实测误差、通过/失败/未测项、剩余偏差。任务汇报与报告结论一致。


## 插接与材质的近景复核

按当前 SKILL.md 对每款接口单独核对局部轴、背视镜像、线序与来源；保留已插接的主机端和模块端近景，不能以整机远景或轮廓 IoU 代替。对插口检查中空、插入段、止挡、该型号外侧塑料颜色与内部阴影，未知项禁止生成连接线。纸贴验收包含原色、金色、半透明与斜视；检查孔壁、卡扣、不同高度面和字体/刻字是否丢失。抓图时清除任务浏览器缓存，核对实际加载的 metadata/artifact hash；网站资产应以 hash 版本化，避免新几何配旧贴图。
